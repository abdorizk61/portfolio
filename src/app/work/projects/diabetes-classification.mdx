## Project Overview

In this project, I designed and trained an Artificial Neural Network (ANN) to classify medical patient data and predict diabetes diagnoses. The goal was to build an end-to-end machine learning pipeline that handles messy real-world clinical data and delivers high precision and recall to assist in medical screening.

---

## Key Highlights & Pipeline

- **Exploratory Data Analysis (EDA):** Analyzed medical features (Glucose levels, Insulin, BMI, Age) to detect distribution skews, feature correlations, and potential outliers.
- **Data Preprocessing & Cleaning:** 
  - Handled biologically impossible zero-values (e.g., zero blood pressure or insulin) using statistical imputation.
  - Applied robust feature scaling to normalize input distributions for stable gradient descent.
- **Model Architecture:** Built a multi-layer deep learning classifier using **TensorFlow / Keras** with optimized activation functions, dropout regularization to prevent overfitting, and learning rate scheduling.
- **Evaluation & Performance:** Evaluated using critical medical diagnostics metrics, focusing heavily on **Recall** and **ROC-AUC** to minimize false negatives.
