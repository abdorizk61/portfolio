## Project Overview

In this project, I developed an advanced, real-time computer vision system capable of detecting, identifying, and tracking multiple moving objects across dynamic video streams. Built using the **YOLO** architecture and optimized for frame-rate consistency, the system generates persistent tracking IDs across occlusions and motion blur.

---

## Key Highlights & Pipeline

- **Object Detection with YOLO:** Utilized modern YOLO models for high-speed, accurate multi-class object detection.
- **Persistent Tracking:** Integrated object tracking pipelines to maintain consistent IDs across consecutive video frames, mitigating identity switches.
- **Bounding Box Annotation & Analytics:** Built automated visual overlays displaying confidence scores, class labels, and tracking trajectories.
- **Performance Optimization:** Tuned inference parameters and batch processing to ensure smooth real-time video feed analysis.
