## Project Overview

The Egyptian real estate market is notoriously heterogeneous, with property values influenced heavily by compounding factors such as location micro-zones, payment terms (cash vs. multi-year installments), property categories (villas, duplexes, penthouses, apartments), and inflation trends.

This project delivers an **end-to-end automated property valuation system** designed to predict real estate prices accurately across Cairo, Giza, New Cairo, Sheikh Zayed, and coastal hubs. The solution integrates an advanced regression modeling pipeline with an interactive, dark-mode **Cyber-HUD valuation terminal** designed for real-time inference and telemetry monitoring.

## Architecture & Machine Learning Pipeline

```
[ Raw Property Listings ]
          │
          ▼
[ Data Cleaning & Normalization ]
   ├─ Location standardization & outlier trimming
   ├─ Feature extraction: price per sqm, bedrooms/bathrooms ratio
   └─ Log1p transformation on skewed continuous targets
          │
          ▼
[ Feature Engineering & Preprocessing Pipeline ]
   ├─ Categorical encoding (Target Encoding + One-Hot)
   ├─ Missing value imputation strategies
   └─ Standard scaling on numeric dimensions
          │
          ▼
[ Model Stacking Ensemble ]
   ├─ Base Models: LightGBM, XGBoost, CatBoost, GradientBoosting
   ├─ Meta-Estimator: Ridge Regression
   └─ Cross-validation: 5-Fold Stratified K-Fold
          │
          ▼
[ Real-Time Inference Engine (Streamlit HUD) ]
   ├─ Latency telemetry (< 15ms per inference)
   ├─ Confidence interval boundaries (±15% valuation bracket)
   └─ Model parameter payload inspection
```

## Key Highlights & Innovations

- **Log-Space Target Transformation:** Mitigated heavy right-skewed pricing distributions by training estimators on $\log(1 + y)$ and mapping predictions back via $\exp(y) - 1$.
- **9-Feature Telemetry Schema:** Evaluates properties across 9 core signals:
  - `location`: Micro-region / governorate identifier
  - `description`: Text features enriched with amenity tags (parking, pool, gym, security)
  - `type`: Architectural property class
  - `size_sqm`: Total surface area in square meters
  - `bedrooms` & `bathrooms`: Layout composition
  - `is_studio`: Binary indicator for open-plan units
  - `payment_method`: Cash, installment, or mixed terms
  - `available_from`: Availability timeline
- **Interactive Cyber-HUD Interface:** High-contrast terminal dashboard featuring live telemetry metrics, Cairo timestamp synchronization, dynamic confidence meters, and debug payload drawers.
