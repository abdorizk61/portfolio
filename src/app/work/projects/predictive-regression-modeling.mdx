## Project Overview

This project focuses on designing an end-to-end predictive modeling pipeline to solve continuous regression challenges. Using real-world datasets, the goal was to extract actionable patterns, engineer meaningful features, and train regularized regression algorithms to minimize prediction error.

---

## Key Highlights & Workflow

- **Exploratory Data Analysis (EDA):** Analyzed multi-variable correlations, skewness, and feature importance matrices using Seaborn and Matplotlib heatmaps.
- **Advanced Feature Engineering:** 
  - Transformed highly skewed numerical distributions using log transforms.
  - Implemented one-hot and target encoding for high-cardinality categorical variables.
  - Imputed missing values dynamically using median/mode and KNN strategies.
- **Model Training & Cross-Validation:** Trained and evaluated multiple linear and ensemble regression models (Ridge, Lasso, Random Forest, XGBoost).
- **Optimization:** Utilized K-Fold Cross-Validation and GridSearchCV for hyperparameter tuning, optimizing for Root Mean Squared Error (RMSE) and R-squared score.
